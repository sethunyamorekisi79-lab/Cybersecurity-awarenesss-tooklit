# Basic Cybersecurity Checklist
## Individual / Small Business
### Password Protection
[ ] 12+ characters containing upper case, lower case, numbers and symbols
[ ] Unique password for all accounts
[ ] Multi Factor Authentication
[ ] Password manager
### Device Protection
[ ] Automatic updates for OS and anti-virus
[ ] Activate firewall
[ ] Screen lock after 2 mins of inactivity
[ ] Encrypt hard drive (BitLocker/FileVault)
### Network Protection
[ ] Change default password on router
[ ] WPA3/WPA2 encryption
[ ] Disable remote management
### Data Protection
[ ] Weekly backups (3-2-1)
[ ] Don’t plug in USBs you don’t know
